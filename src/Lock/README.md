# Foundation Lock

> [!WARNING]
> **This is a read-only repository!** For pull requests or issues, see [stellarwp/foundation](https://github.com/stellarwp/foundation).

Foundation Lock provides the shared lock contract, ownership tokens, and an
in-memory implementation for tests and single-process work. Persistent database
and Redis implementations are available through separate Foundation packages.

## Installation

```shell
composer require stellarwp/foundation-lock
```

## Documentation

See the [Foundation Lock documentation](https://foundation.stellarwp.com/components/lock/)
for backend selection, configuration, lease handling, failure behavior, usage
examples, and testing.
